THE BOSS

Privacy policy.

Last updated: 18 October 2026.

This policy covers the personal Google Drive encrypted-backup connection described on the homepage. It covers that connection and this informational website, rather than every feature of THE BOSS application. The connection is operated by the owner of the Google account used for this personal backup.

Information accessed

  • The Google account email address and storage-quota information needed to verify the account and available capacity.
  • Files created by or explicitly made available to this app under the drive.file permission, including the owner's encrypted backup-repository files and related storage metadata.
  • OAuth credentials needed to maintain the authorised Google connection. The website does not request, receive or store these credentials.

The connection does not request access to all existing Drive files, Gmail or Google Photos. An owner-authorised encrypted off-site copy has been stored and independently read-checked.

Purpose and use

Google data is used only to verify the owner's backup destination and, when authorised, store, check and retrieve the owner's encrypted backups. It is not used for advertising, sold, used to build advertising profiles or used to train general-purpose AI models.

Encryption and storage

For authorised backup uploads, restic encrypts backup contents on the owner's computer before rclone transfers encrypted repository files to Google Drive. Google may retain the uploaded ciphertext and operational metadata such as account identity, object names, sizes and access times. The repository password is held separately and is not supplied to Google Drive.

OAuth credentials are stored in an encrypted local rclone configuration restricted to the owner and the local system. They are not embedded in this website or ordinary verification reports. Recovery passwords, application recovery secrets and operating-system recovery keys are not published here or included in website files.

Sharing and service providers

The off-site backup storage provider is Google Drive, under the owner's Google account. Public website hosting is provided by GitHub Pages. The hosting provider receives ordinary web-request information; it does not receive private backup contents or OAuth credentials through this site.

There is no sale or sharing of Google user data for advertising. THE BOSS's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

The owner controls retention and deletion of stored backup files. This connection does not currently run recurring backups or automatic pruning. Revoking the app's access in Google Account settings stops authorised API access; it does not itself delete files already stored in Drive. Deleting backups is a separate owner-controlled action.

This website

The site has no sign-in form, backup-upload form, advertising, analytics script or tracking code added by its operator. GitHub Pages may log visitor IP addresses and other request information for security and service operation; see the GitHub privacy statement. Other services involved in delivering the site may retain normal network or DNS metadata.

Questions and updates

Contact usergrok203@gmail.com about this connection or this policy. The date above will change when the operator updates the policy. Any future change to Google permissions or data use should be reflected here before that change is enabled.
